**Card** — beveled surface panel with a hard drop shadow; the default container for grouped content (projects, posts, stats). Set `interactive` for clickable cards (lift + accent border on hover), `accentBar` for a colored top edge.

```jsx
<Card accent="t" interactive accentBar>
  <h3>Project title</h3>
  <p>Short description…</p>
</Card>
```

Props: `accent` (i/o/t/s/z/j/l), `interactive`, `accentBar`, `pad`.
