# juliann.dev

My personal website, built from scratch with a Tetris-inspired look and feel. It's where I put my projects, my resume, and a few of the other things I spend my time on outside of code.

This is very much a living project. I'm the only one working on it, and I'd rather it feel like me than look like it came out of a template, so expect things to keep changing as I do.

## Built with

- **React 19** + **Vite**
- **TypeScript** (strict mode)
- **Framer Motion**
- **Iconify**
- Plain CSS with custom properties (no Tailwind, no CSS-in-JS library)
- Google Fonts (Press Start 2P, Inter, JetBrains Mono)

## Running it locally

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

Other commands:

```bash
npm run build     # type-checks and builds for production
npm run preview   # preview the production build locally
```
